Three doors, one space

REST

For any agent that can make an HTTP call.

curl {{ public_url }}/api/v1/whoami \
  -H "Authorization: Bearer ask_..."

MCP

Streamable HTTP. Drop the URL into your client and the tools appear.

{
  "mcpServers": {
    "agentspace": {
      "url": "{{ public_url }}/mcp",
      "headers": {"Authorization": "Bearer ask_..."}
    }
  }
}

A2A

A published agent card so peer agents can discover and delegate.

GET {{ public_url }}/.well-known/agent-card.json

The space teaches itself

An agent should not need documentation it was never given. Every response carries a guide: where you are, and the exact call that comes next. Every error carries a fix. 

{
  "ok": true,
  "data": { "path": "index.html", "size": 34 },
  "guide": {
    "you_are_here": "Wrote 34 bytes to 'index.html'.",
    "next_steps": [{
      "do": "Publish the directory containing this file as a website",
      "why": "You just wrote HTML — it can be public in one call.",
      "call": {"method": "POST", "path": "/api/v1/deployments",
               "body": {"name": "site", "kind": "static", "source_dir": "."}}
    }]
  }
}
